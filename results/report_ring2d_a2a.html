1 · makespan

每个方案把同一批 2,256 条流排完。makespan 是最后一条流结束的拍， 比 data_span 多 16 拍，那是一趟请求-授权时延。 轮数下界是最热链路负载；whole_ring 把下界从 60 抬到 192， 因为整环互斥、不能空分复用。

最短的是 fixed · g=2 · interval，120 拍。 同面积里最短的 free_at 方案是 fixed · g=2 · fill=arc_asc，1,586 拍。 whole_ring 是 5,280 拍，最慢。

2 · 面积 / makespan Pareto

两轴都是越小越好：面积向左，makespan 向下。绿线连非支配点。 蓝点共用一块 free_at 仲裁器，所以叠在同一条竖线上；绿点是 interval，红点是 whole_ring。

前沿：fixed · g=2 · fill=arc_asc（1,586 拍 / 10,968 bit）、fixed · g=2 · interval（120 拍 / 189,528 bit）。 interval 用 17.3× 的仲裁器状态， 把 makespan 从 1,586 收到 120 （13.2×）。 其余 free_at 方案和 whole_ring 都在这条前沿内侧。
批量调度按完全流水计，表里的 makespan 没有再加 T_sched。 free_at 的 T_sched 是 69 拍， interval 是 138 拍。 即便把 interval 的 138 拍一次加上， 合计 258 拍仍然短于 free_at 的 1,586。
