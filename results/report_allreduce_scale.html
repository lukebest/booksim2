Near-optimal Allreduce 研究报告

2D mesh（非 torus）· H=7 V=9 RAMP=1 ramp_bw=1 · INC_LAT=3cy · NODE_RED_LAT=12cy · 规模 4x4, 6x8, 8x8, 12x16, 16x16 · m=1–5 flit

1. 物理模型与设计空间

每个 mesh 节点通过 router 与 4 邻连接。链路延迟：同行 H=7 cycle，同列 V=9 cycle； PE↔router ramp 各 1 cycle，链路带宽 1 flit/cycle。

Allreduce 需在全部 N 个节点完成归约并分发最终结果。本研究探索 2×2 设计空间：

Reduce + BroadcastReduce-Scatter + AllGather
INC reduce
路由器内 merge，3 cy/flit		 维度树 reduce 到中心 root，再多播树 broadcast Hamilton 环 RS + 库中最优 AG（allgather_scale_sweep.json）
无 INC
下 ramp→node 计算→上 ramp，共 12 cy		 同上，但每跳 merge 需 node 绕行 环 RS（高 merge 代价）+ 最优 AG

调度采用刚性零缓冲打包器（sched_zerobuf_compare.py）：每链路每 cycle 至多 1 flit， 每 ramp 每 cycle 至多 1 flit。RS+AG 中 AG 段 makespan 取自已有 allgather 最优零缓冲结果。

2. 理论下界

对每种 (规模, m, reduce 模式) 计算四类下界取 max：

T = max(tree_latency, downramp_final, bisection)
T_rsag = max(downramp_rsag, bisection, diameter_pair)

tree_latency 含顺序 reduce + broadcast 两阶段；merge 代价按 INC_LAT 或 NODE_RED_LAT 计入关键路径。

7. 分析结论与推荐

  • 全局最优 reduce 模式：INC 在 25/25 个配置中胜出，无 INC 在 0/25 个配置中胜出。 INC 的 per-merge 代价为 3 cycle/flit，无 INC 需 12 cycle 完整 ramp 绕行；当 merge 次数少（小 mesh + 树形 RB）时 INC 优势不明显， 但当 RS 阶段需要沿环逐跳 merge（N-1 次）时，INC 可将 RS 阶段从数百 cycle 压到与最优 AG 可拼接的量级。
  • 算法结构选型：Reduce+Broadcast (RB) 在 14/25 格胜出，RS+AG 在 11/25 格胜出。 小 mesh（4x4/6x8/8x8）上 RS+AG 在 INC 模式下占 9/15 格； 大 mesh（12x16/16x16）上 RB 在 INC 模式下占 8/10 格。
  • 临界点：H=7 V=9 下 16×16 mesh 直径约 240 cycle；当环 RS 的 O(N) 步延迟超过树形 RB 的直径延迟时， 即使 AG 段采用库中最优方案也无法挽回，tree_reduce_bcast 稳定为 makespan 最优（比值 ~1.00–1.05）。
  • 无 INC 场景：所有规模上 tree_reduce_bcast 均为该模式下的最优方案（RS+AG 的 RS 段因 12cy/merge 代价过高）。 大 mesh + 大 m 时 makespan 相对下界比值显著升高，表明无 INC 时 reduce 代价成为主导瓶颈。
  • 推荐配置：
    • 有 INC + 小/中 mesh + 小 m → ring RS + 最优 AG
    • 有 INC + 大 mesh + m≤5 → tree reduce + broadcast
    • 无 INC（任意规模）→ tree reduce + broadcast（避免环上多次 12cy 绕行）

方案族说明

  • tree_reduce_bcast：每源沿维度序路径 reduce 到 mesh 中心 root（3cy/merge 或 12cy 绕行），root 弹出后再沿维序多播树 broadcast 到全部节点。
  • ring_*_rs_optag：全局 Hamilton 环（蛇形构造）做 reduce-scatter，每节点沿环发送并逐跳 merge；完成后拼接库中该规模的最优 allgather 方案（如 hybrid_v_bi_B2、ring_bi 等）。
  • hybrid_hB（横带局部环 RS + 全局树 RB）：在本次扫描中均未超越 tree_reduce_bcast，未进入任何最优格。
