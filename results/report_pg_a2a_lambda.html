10. 均匀注入率 all-to-all（健康 XY / ≤2R+≤4L Super-turn）

每个存活计算节点以相同伯努利注入率 λ 发单 flit 包， 目的均匀落在其余存活节点（与 rg_steady_des.Injector 同口径）。 λ ∈ {0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.36, 0.37, 0.38, 0.39, 0.40, 0.41, 0.42, 0.43, 0.44, 0.45, 0.46, 0.47, 0.48, 0.49, 0.50}。 warmup=1500 cy，measure=4000 cy，Q=19， flit=512 bit。 时延 = t_eject − t_gen（仅统计 measure 窗内产生的包，测量结束后排空）。 有效带宽 = 交付 flit 数 / measure 周期（全网；即数据量 / makespan， open-loop 下 makespan = 测量窗）。 accepted = 交付包数 / (A · measure)。 all-good 路由 = 健康 mesh XY（1 VC，组合逻辑）。 partial-good 路由 = M0s Super-turn（turn-model，硬顶 2 VC）。 故障目录 = ≤2 死 router + ≤4 无向链路、router–链路不重叠， 每个 (nR, nL) 格子 1 个样本（seed=0），共 14 个场景 。 原始 JSON：results/pg_a2a_lambda.json。
