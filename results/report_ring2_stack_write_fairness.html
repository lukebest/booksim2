3D 堆叠 NoC：按 top die 分组的写带宽

bottom die 横环 4 cycle / 纵环 6 cycle / 挂接点转向 5 cycle。 D2D landing 在 bottom die 上有两个独立接口（接横环、接所在列纵环）， 并用 HPCA'22 SWAP 与有界落地 buffer 解交叉死锁。 带宽口径为瞬时带宽，写带宽单位为 flit/cycle。 workload：burst 128 B、stride 4096 B、 tiling_size 64 KB × 4 tile / core （每核 2048 笔 WriteNoSnp，共 122,880 笔）。 地址按 128 B 交织到 96 个 HA，每核覆盖全部 HA （每核打到同一 HA 的次数 21–22）。 每 core outstanding = 512。 每个 HA 跟踪表 32 项，满了走请求 retry （RetryAck → PCrdGrant → 重发 REQ），不是源端控速。

S0 没有源端流控——只要 outstanding 有空位、ring 上有 slot 就发。 S1 再加 AIMD 源端控速。HA 跟踪表满触发的是 CHI 请求 retry，不是源端控速。

结论

  1. outstanding 设为 512。 无拥塞的 WriteNoSnp 往返 = REQ 去程 + DBID 回程 + WriteData 去程 （4 flit 流水，最后一拍比第一拍晚 3 cycle）+ Comp 回程。 最坏一对 (core 4, HA 231) 的去程 58 cycle、回程 147 cycle，合计 413 cycle。额度从 REQ 上环一直占到 Comp 回来。 窗口 512 相对最长 RTT 413，长路径上 core 会先把 512 个槽占满再等 Comp。 本批次每 core 2048 笔，大于窗口 512，实测峰值占用 512，outstanding 上限已经打满——S0 能发出去的条件只剩 outstanding 空位和 ring slot。
  2. HA 跟踪表满是请求 retry 机制。S0 不另加源端控速，S1 才控速。 每个 HA 同时只能收 32 个请求；再来的 REQ 走 RetryAck → PCrdGrant → 重发 REQ，占真实 RSP/REQ 带宽。 S0 完成 122,880/122,880，makespan 88,504 cycle， RetryAck 93,829 次，有效并发是名义值的 13.6%； S1 完成 122,880/122,880，90,638 cycle， retry 99,618。 两个方案都排空，没有活锁、没有停在停滞检测器上。
  3. 全程完成量均衡，瞬时不均衡。瞬时均衡度用 E[Jaint]。 六个 die 写完同样多的 flit，Jain(E[x]) = 1.00，完成量 max/min = 1.00。 每个 50-cycle 窗上再算组间 Jain，竞争窗口内 S0 的 E[Jaint] = 0.8300， S1 为 0.8277 （约 68.3% 的窗 < 0.90）。 均衡流量下理想每组写带宽是 1.524 flit/cycle （总 WriteData / 综合下界 / 6；下界 53,760 cycle， 由纵环切割决定）。S0 全程平均每组 0.9256， 约是理想的 60.7%。 虚线画在组写带宽曲线上。
  4. 对分 / 环带宽按瞬时口径看。 S0：top die REQ 瞬时 78.3%（接近打满）；D2D 对分 REQ 瞬时 49.0%（未打满）；横环 REQ 瞬时 95.8%（打满）；纵环 RSP 瞬时 93.8%（打满）。 S1：top die REQ 瞬时 75.0%（接近打满）；D2D 对分 REQ 瞬时 49.0%（未打满）；横环 REQ 瞬时 97.9%（打满）；纵环 RSP 瞬时 93.1%（打满）。 “打满”看最忙那条 CHI VC 的瞬时峰值是否达到该织物有向边数； 全程平均会把排空尾部算进去，会低估峰值占用。 D2D 对分是 48 对双向 SerDes；bottom 落地后横口、纵口可同时上环。
  5. SWAP + D2D 落地 buffer 解除交叉死锁。S0 SWAP 112,947 次（H↔V 55,047，D2D 57,900）；S1 115,127 次（H↔V 57,030，D2D 58,097）。下降的 WriteData 与上升的 Comp/PCrd 在 D2D bridge 互换 hop；远列转向在横↔纵挂接点互换。落地 buffer 峰值 16。

在 1-tile 同构写上扫发送端/接收端、窗口/速率、触发方式。 目标：E[Jaint] → 1，每组写带宽 → 理想 1.524 flit/cycle。 收益 = √(E[Jaint] × 写带宽/理想)。代价是相对门数 （总线 ≫ HA 状态机 ≫ 每核寄存器 ≫ 每 die 计数器）。 绿点是代价–收益非支配面。扫次 4710.8 s， n_txn=30,720。当前面：S16 HA 授权压低瞬时公平（E[Jaint]=0.7605）且带宽不升；S17 转向让行接近 S1（0.8292 / 58.0%）；S18 RTT 窗 Jain 最高（0.8873）但带宽只有理想的 48.0%；S20 漏桶比周期配额更好（Jain 0.8703，带宽 56.3%）但仍低于 S0；去掉总线的本地 AIMD 掉到 S0 以下（Jain 0.8497，带宽 58.4%）——升窗仍靠路径等级；质量最优仍是 S1 无路径抵消（Jain 0.8742，带宽 62.0%）。非支配面稳定在 S0 无控 / S1 无路径抵消。

3　理论下界

链路下界（分 VC 取最大）46,096最忙的一条有向链路上、单个 VC 需要搬运的 flit 数
　└ 分 VC 明细dat 46,096 / req 11,524 / rsp 25,600DAT 是 4 flit/笔，通常是它决定链路下界

　└ 分织物明细d2d 8,960 / h 35,840 / top 8,960 / v 53,760纵环 144 条、横环 48 条，横环少但只承担换列流量
