# simple2d 专家汇报（8×6）

**口径：** 8×6 mesh / 48 节点 / all-to-all / m=1 / σ=1 / `buf_depth=20` / `T_rtt=16`。λ 单位：包/节点/拍。
**数据：** `results/bisect_lat_8x6.json`（2026-08-18，warmup 3000 + measure 12000）、`results/simple2d_8x6.json`。完整叙述见 `results/report_islip2d_8x6.html` §9.3–9.5、§11a。

## 0. 结论

λ 是每个节点每拍注入一包的概率（包/节点/拍）。all-to-all 下目的在其余 47 个节点上均匀抽取。λ 是最大仍稳定的注入率：再往上源队列就会无限涨。8×6 mesh 均匀流量的解析上界是 0.490（12 条切面链路 ÷ 跨切概率 0.51064）。

all-to-all 下三条 mesh 配置：

- **mesh_base**：λ = 0.41，切面 83.5%（峰值 83.9%）。空载最快（平均 40 / p99 83），稳定区尾巴最肥（p99/平均 5.00×），λ 处 p99 479 拍。切面没用满。
- **simple2d**：λ = 0.35，切面 71.7%（峰值 79.5%）。吞吐低于基线。空载与 islip2d 相同（56 / 99），稳定区几乎水平，p99/平均 2.49×。
- **islip2d**：λ = 0.47，切面 95.8%、峰值 100%。唯一把切面用满的。空载与 simple2d 相同，尾巴最干净（1.81×），λ 处 p99 119 拍。

λ 判据：测量窗内 backlog 斜率 < 0.002 **且** accept_ratio ≥ 0.98。虚线（越过 λ）上的时延是有限窗的性质，不是 fabric 的性质。本节 λ 精确到网格步长（mesh 膝部 0.35 / 0.38 / 0.41 / 0.47）。

同 λ 才比时延。mesh_base 自己的 λ=0.41 上，islip2d 的 p99 对基线大约 **4×**，平均只大约 **1.5×**——尾部收益大于平均。simple2d 在 0.41 已经失稳，只能在它自己的稳定区（≤0.35）上读。

## 2. 算法（核对用，不展开）

**删掉的三件：** 区间占用表、每链路 grant 指针 / 两级 iSLIP、迭代。

**留下的一句：** 一轮 = 一组链路不相交路径（LDPS）。每源从残余 VOQ 按 RR 拿出候选；能放下就授 1 条。

**路径（最多一个坏节点 F）：**

1. `s` 或 `d` 是 F → 流不存在。
2. 否则 XY；XY 穿 F 则 YX。
3. `s,d,F` 共线（XY=YX）→ U 绕行：离开该线一跳，平行走过 F，再回来。8×6 任一行/列至少有一侧可走。

**稳态模型（和批量的差别必须说清）：**

- 批量：轮次不重叠，织物在轮初是空的，所以「只授 1 条、不挖洞」几乎贴割界。
- 稳态：每拍一轮、`t0` 固定为 `now+RTT`，上一拍在更远 hop 上留下的洞下一拍可以用——但 **CA 不搜索最早空隙**。H=7 / V=9，前缀差一跳就是 7–9 拍，滑动 t0 才会触发 free_at 棘轮。
- 实现上占用按拍记账（`interval`），匹配规则是 simple2d。这是「便宜 CA、诚实金属」，不是把数据面也塌成一个前沿寄存器。

## 3. 未做 / 边界

- simple2d 的稳态扫描只覆盖健康 mesh；单坏点只有批量轮次，没有故障下的 λ / p99。
- 没有 `m=4` / `σ=2` 的 simple2d 稳态曲线；主扫描里这两档会改谁赢，simple2d 未重跑。
- 没有 ring_simple2d。
- λ 网格分辨率：0.35 稳定、0.38 失稳，真膝部在两者之间。
- 51 条既有断言未因本次曲线扩展而增补 simple2d 稳态项。
